## 3. architecture boundary proof (`pnpm lint:boundaries:prove`, exit 0)

각 증명은 위반 파일을 임시 생성 → depcruise 실행 → 기대 rule로 실패 확인 → fixture 제거.

| 증명 | 주입한 위반 | 기대 rule | 실제 결과 |
| --- | --- | --- | --- |
| (a) | kernel test가 자기 `lib/hash.ts` import | tests-through-entrypoints | error tests-through-entrypoints (발화) |
| (b) | kernel `lib/domain`이 `node:fs` import | domain-is-pure | error domain-is-pure (발화) |
| (c) | 임시 `packages/zz-proof`가 kernel `lib/` import | entrypoint-boundary-across-packages | error entrypoint-boundary-across-packages (발화) |
| (d) | 임시 `packages/action/lib/domain`이 platform import | package-layering 또는 domain-is-pure | error package-layering-action (발화) |
| (e) | 임시 `packages/contracts/lib`이 `packages/policy/evaluate.ts`(schema 아님) import | contracts-schema-only | error contracts-schema-only (발화) |

5개 모두 의도한 rule로 실패. 실패하지 않으면 script가 exit 1. 실행 후 작업 tree에 fixture 없음.

핵심: `depcruise packages`가 **11 modules, 15 dependencies cruised**(0이 아님). typescript 7.0.2에서는 depcruise가 0 modules만 분석해 무효 통과였고, 이것이 ACR-0001의 근거다.
